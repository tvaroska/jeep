# Architecture Decision Records (ADRs)

This directory holds **immutable** ADRs — one decision per file, named
`ADR-{NNN}-{slug}.md` (e.g. `ADR-001-vertex-backend.md`).

- ADRs are immutable once accepted. To change a decision, write a new ADR that
  **supersedes** the old one (set the old one's status to `superseded by ADR-NNN`).
- Every ADR is also summarized in the append-only [`DECISIONS.md`](../../DECISIONS.md);
  the ADR holds the standalone detail, the log holds the running history.
