# jeep — Open Questions

Unresolved decisions and proposed changes to protected `spec/` content. This is
where agents PARK proposals instead of editing protected files during `/implement`
(see `CRITICAL.md`). Part of `spec/` but intentionally mutable — a working queue.

When a question is resolved: record the outcome in `DECISIONS.md` (and an ADR in
`design/decisions/` if architectural), apply the agreed change to the relevant
`spec/` file, then remove or strike the question here.
